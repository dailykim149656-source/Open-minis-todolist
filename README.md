# Open Minis Todo List

> **iPad Air 4 한 대와 Open Minis만으로 웹 앱을 만들고 실제 배포까지 진행한 실험 프로젝트입니다.**

별도의 PC나 Mac 없이 iPad Air 4에서 Open Minis를 이용해 기획, 바닐라 HTML·CSS·JavaScript 구현, 동작 검증, Git 커밋, GitHub 저장소 생성, GitHub Pages 배포까지 전 과정을 완료했습니다.

이 프로젝트는 모바일 환경의 AI 에이전트만으로 간단한 웹 서비스를 개발하고 공개 배포할 수 있는지 확인하기 위해 제작한 투두리스트입니다.

## 프로젝트 목표

- iPad Air 4만으로 웹 앱 개발부터 배포까지 완주하기
- Open Minis를 활용해 소스 생성, 테스트, Git 및 GitHub 작업 자동화하기
- 별도의 빌드 도구나 프레임워크 없이 정적 웹 앱으로 간단히 배포하기

## 기능

- 할 일 추가, 완료, 삭제
- 전체 / 진행 중 / 완료 필터
- 완료 진행률 표시
- 완료 항목 일괄 삭제
- 브라우저 `localStorage` 자동 저장
- 모바일 반응형 및 키보드·스크린 리더 접근성

## 실행

빌드 과정이나 패키지 설치가 필요하지 않습니다. `index.html`을 열면 됩니다.
